Infrastructure Blueprint

Designed for reliability, clean volume isolation, and effortless updates on any Linux VPS, homelab, or Raspberry Pi node.

Isolated Container Stack

Runs cleanly inside a dedicated bridge network (gitea-net) separating the application tier from database storage.

SSH Passthrough & TLS

Pre-mapped SSH port routing (2222:22) avoids conflicts with host SSH daemons while keeping git push fast and secure.

Flexible Database Backend

Supports zero-config SQLite3 for single-user setups or production PostgreSQL/MySQL containers for multi-team organizations.

Deployment Workflow

Follow these four steps to bring your Srijan-XI/Gitea-server instance online.

1

Clone the Repository

Pull the configuration templates and directory structure onto your host machine.

git clone https://github.com/Srijan-XI/Gitea-server.git && cd Gitea-server
2

Configure Environment Variables

Set strong database credentials and verify UID/GID ownership for persistent volume mounts.

cp .env.example .env && nano .env
3

Launch Services in Detached Mode

Start Gitea and its backing database in the background with automatic restart policies.

docker compose up -d
4

Complete Initial Web Setup

Open http://<your-server-ip>:3000 in your browser, verify the pre-filled database settings, and register your primary administrator account.
